# dsh-go：可选轻量知识导航

[原生面板](<../lib/panel.js>) 是领域包的次要入口，服务于同一个宿主 agent 的对话，不是新助手，也不是护肤打卡控制台。主要能力由 [技能入口](<../skill/SKILL.md>) 提供；没有 Go 面板也不影响使用。

## 面板职责

- 提供护肤主题导航、知识范围说明和可选问题示例。
- 让用户主动选择讨论方向，按宿主支持的方式进入当前对话；准备输入内容不等于自动发送。
- 提示科普与医疗边界；不在面板中生成个体诊断或风险分数。

不展示认知等级、护理复杂度、课程完成率、打卡天数或档案状态灯。不要求「先建档再使用」，也不把打开主题或点击按钮当作学习完成。

## 交互边界

不新增常驻输入框胶囊。面板内主题入口只负责导航或帮助准备问题，不夹带档案命令、不偷偷发起模型任务或上传数据。用户是否发送、如何修改问题，由用户决定。

具体投放位置与入口以实际 [包清单](<../package.json>) 和宿主支持为准，不通过文档承诺某设备已出现面板。没有 `dshGo` 服务时，可选面板不应妨碍技能提供者工作。

## 无专用用户状态

面板不读取、创建或写入旧 `~/.dsh/skin-care/profile.json`，不建立替代数据库，不自动迁移历史内容。没有档案不是错误，也不应显示建档催促。

用户明确希望查看旧档案时，由会话按 [技能规则](<../skill/SKILL.md>) 使用只读兼容工具，而不是让面板在加载时自动读取。需要跨会话连续性时遵循宿主现有记忆政策与工具；无记忆能力时保留在会话中，或在用户请求时提供摘要。

## 运行与安装

发布运行时为 JavaScript／Node.js，导航不依赖 Python 或独立常驻服务。维护者工具是否使用 Python 与面板运行无关。通过同一 npm 包经 DSH 宿主安装，见 [安装说明](<../README.md>)，无需另建一套护肤插件或存储。

本文件说明面板设计与验收边界，不表示当前主机已安装、已刷新或已验证新版。验证时应检查：

- 实际加载的版本与本地工作副本一致；
- 有 Go 时导航可用，无 Go 时技能仍可加载；
- 没有常驻护肤胶囊、打卡或课程完成写入口；
- 打开面板和点击主题不会读写用户档案；
- 进入对话不会绕过用户发送意愿。
