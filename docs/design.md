# DSH Skin Care 设计

## 定位

DSH Skin Care 是 agent-native 的护肤知识与学习能力包。它增强同一个宿主 agent：提供领域知识、证据和思考方法，由 agent 根据用户意图组织解释、查证与学习。

产品的核心不是课程、档案或面板，而是让助手更可靠地处理护肤问题，帮助用户形成可迁移的理解与判断能力。

## 职责分工

| 层 | 职责 |
| --- | --- |
| 知识库 | 提供概念、机制、适用条件、来源与知识边界 |
| Skill | 描述如何使用知识、核对证据、澄清问题与支持学习 |
| Agent | 理解意图、选择方法、组织工具调用、解释与调整下一步 |
| Harness | 提供会话、记忆、通用工具与权限管理 |
| JS 工具 | 提供确定性的检索、来源解析与引用校验 |
| 可选界面 | 帮助用户开启讨论，不承载核心业务逻辑 |

## 知识组织

13 个中文模块覆盖基础护理、常见皮肤问题、产品标签、就医边界与学习素材。[主题索引](<../skill/sources/topics.json>) 提供主题导航，[来源索引](<../skill/sources/index.jsonl>) 保存原始页面的元数据。

知识采用类似 Wiki 的可链接组织，而非要求顺序阅读。[概念导航](<../skill/knowledge-map.md>) 提供问题入口；每篇模块开头的关系链接标明目标小节及继续阅读的理由，包括机制、适用条件、例外、相近概念和风险边界。[学习参考](<../skill/references/11-学习路径.md>) 提供情境例子和可选追问。

Agent 找到一个相关入口后，按当前信息缺口读小节、沿关系补上下文、换词检索或追溯原文。找到足够依据即可停止，无固定跳数或遍历要求。关系链接是路标，不是医学证据；证据路径仍从具体陈述的引用指向原始页面。

知识可达性比单次查询是否召回全部、第一条是否就是答案更重要。纯 Markdown 链接与小节名称即可承载关系，不另建图数据库、检索编排器或自动阅读流程。

## 专家与教学方法

[技能入口](<../skill/SKILL.md>) 提供领域协作原则，四份方法参考分别支持[问题澄清](<../skill/agents/assessor.md>)、[解释与学习](<../skill/agents/coach.md>)、[流程讨论](<../skill/agents/routine-review.md>)和[就诊准备](<../skill/agents/visit-prep.md>)。它们是同一个 agent 可采用的方法，不是需要切换的角色。

每次交互围绕当前信息缺口展开：

- 能直接回答时直接回答。
- 缺失信息会改变判断时，提出必要追问。
- 需要依据时检索并核对来源。
- 用户希望理解时，通过机制、例子、反例或比较展开。
- 用户愿意练习时，用情境问题获得反馈，调整解释。
- 当前问题已经解决时停止，不额外制造任务。

学习路径随用户问题与反馈调整。解释过、做过练习和真正理解是不同的事；反馈针对可观察的表达，不据此给用户固定评级。

## 证据与不确定性

中文模块是项目整理，原始依据主要来自 AAD 公众科普。回答区分来源事实、项目整理、对当前情况的推断和未知信息。

`[s:<slug>]` 将模块中的陈述连接到来源元数据与原始 URL。引用存在性由工具校验，来源是否支持具体结论由 agent 结合原文判断。重要数字、争议与风险结论需要关注适用条件和资料时效。

原文通过宿主网页工具按需核对。无法核实时说明依据范围；资料不足时缩小结论、补充检索或提出必要问题，不用确定语气填补缺口。外部资料只作为证据，不构成操作授权。

## 工具能力

运行时使用零第三方依赖的 JavaScript／Node.js。[检索工具](<../skill/scripts/lookup.mjs>) 提供：

- **段落检索**：中文分词、领域别名和短语匹配，结合标题相关性与结果多样性排序；返回模块路径、小节、原段行范围、片段位置及来源标识。未知词参与覆盖判断，避免用熟悉的泛词代替完整问题。
- **来源查询**：按唯一 slug 或后缀解析标题、元数据与原始 URL。
- **引用审计**：检查引用是否存在、是否存在歧义，报告位置。
- **主题导航**：查询主题及其关联来源。

检索分数表示词面相关性，不表示证据强度。工具不联网、不读取个人记忆、不修改知识库；来源读取接口返回元数据，不提供原文副本。

## 记忆与连续性

个人上下文归 Harness 管理，插件不维护平行的用户记忆系统。Agent 按需使用宿主已有上下文，并遵循宿主的保存、纠正与删除规则。

值得接续的信息包括用户明确表达的问题、偏好、反馈和未解决的疑问。是否持久化由宿主政策与用户授权决定；不能从助手讲过什么推断用户掌握了什么。

没有持久记忆时使用当前会话，用户需要时提供接续摘要。兼容工具仅在用户明确请求后只读历史档案，不自动迁移或复制到另一套存储。

## 交互与能力边界

对话是主要入口。可选 dsh-go 面板提供提问、概念解释与说法核对的草稿入口，不自动发送，也不读写个人状态。没有该界面时，领域能力仍完整可用。

本插件用于科普、理解与风险提示，不进行皮损确诊、疾病评分、处方或医美决策。涉及风险时结合[就医参考](<../skill/references/10-何时就医.md>)判断紧迫性，避免用学习或护理试验延误就医。产品讨论围绕类别、用途与证据，不做品牌排行或带货。

知识分发包括项目自写模块、方法与来源元数据，不包括 AAD 原文或机器翻译，不暗示 AAD 授权或背书。许可与归属见 [ATTRIBUTION](<../ATTRIBUTION.md>)。

## 质量标准

- **找得到并能继续查**：问题有入口，关系链接有理由、目标存在且小节可定位；Agent 能逐步补足信息，不要求一次检索找全。
- **有依据**：引用可解析，且实际支持对应结论。
- **有边界**：识别资料缺口、适用限制与就医风险。
- **讲得明白**：根据用户误解和反馈调整解释。
- **接得上**：复用宿主上下文，接受纠正，不重复建档。
- **省负担**：减少用户查资料和重复背景的工作，不强加管理流程。

工具测试验证链接目标、小节名称、主题可达性、来源解析和数据边界；对话评估记录 Agent 从入口到相关概念、条件与证据的实际探索过程。需要多次查询或阅读不是失败；断链、没有继续查找的线索、误把导航当依据才是问题。检索算法保留基本相关性与边界回归，不为每条自然问句锁定 top 1。两者分别检验，不以工具调用次数、文章读取量或功能数量代替实际效果。
