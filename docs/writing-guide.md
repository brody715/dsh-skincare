# 知识模块写作规范

知识模块供 agent 按问题检索和解释。目标是帮助理解与判断，不是提供可无条件照抄的医疗处置模板。

## 1. 从问题与概念组织内容

每个小节回答一个明确问题。标题写出主题或概念，先给核心解释，再给适用条件、反例或相关概念。成分清单、特定人群用法和研究数字放在独立小节，避免基础概念检索先命中大量枝节。

- 概念解释、情境例子和可选自测分别组织。
- 一个段落尽量表达一个可以核对的主张；避免把多个问答或不同疾病的用法塞进同一段。
- 跨主题用具名模块和小节导航，不重复复制结论。关系写清为什么继续读：机制、条件、例外、相近区别、风险或证据，而非只堆「另见」链接。
- 每篇开头的「相关知识与继续查找」提供少量有用邻接关系，并可返回[概念导航](<../skill/knowledge-map.md>)。正文需要时也可内联导航，不要求全互链或相同数量。
- 可采用 `[模块名](<文件.md>)「精确小节标题」——继续阅读的理由`；改目标标题时同步链接。导航是路标，不复制处置结论，也不借目标引用作为本段已核验的证据。
- 不以知识章节安排必修顺序，不根据读过内容生成用户等级或完成状态。

## 2. 引用与支持范围

事实性主张使用来源索引中存在的 `[s:<slug唯一后缀>]`。引用靠近对应陈述；来源相同且适用范围一致的相关陈述可以合并标注，不以固定句数决定引用密度。

核对分为两层：

1. **标识正确**：slug 存在、唯一解析、URL 对应预期页面。
2. **内容支持**：原文实际支持该主张，包含适用人群、疾病背景、条件与局限。

引用审计只覆盖第一层。一个段落列出多个来源不等于每句话都得到支持，更不能把章节标题当证据。

维护时使用 [检索工具](<../skill/scripts/lookup.mjs>) 定位来源，再通过网页工具读取原文。`--read` 仅返回元数据，不表示已读原文。

```sh
node skill/scripts/lookup.mjs --topic acne
node skill/scripts/lookup.mjs --check care/face-washing-101
node skill/scripts/lookup.mjs --url care/face-washing-101
node skill/scripts/lookup.mjs --audit
```

以上命令从包根目录运行；也可使用脚本绝对路径。

无法核验时，收窄或移除未经支持的具体断言，保留需要核查的问题。不能以「这是推断」为危险医疗建议开脱。

## 3. 保留适用条件，不拼接新规则

- 痤疮研究的观察周期不能成为所有护肤品的起效周期。
- 湿疹、毛周角化等特定背景中的用法不能组合成全人群通用上限。
- 使用后改善只能是变化线索，不能排除疾病或证明因果。
- 特定来源中的剂量、频率和孕期限制须保留其范围；不自行换算脸部用量、合并禁忌或生成个体处方。
- 「更适合某些人」不能写成「所有人必须」；「没有查到证据」不能写成「已证明无效」。

出现不适、恶化或危险信号时，不用固定等待周期、护理执行天数或学习阶段阻碍就医。急救风险、需要及时评估和一般咨询分别表达；具体条件参考 [就医模块](<../skill/references/10-何时就医.md>)。

## 4. 区分知识、推断和教学设计

中文模块是项目整理，不是 AAD 原文。将来源支持的事实与作者归纳分开；假设情境、类比和可选追问应明确是教学设计。

示例：

> 教学类比：可以把减少水分散失类比为给容器加盖；这个类比只解释一个机制，不代表皮肤是容器，也不意味着所有保湿产品只起封闭作用。

作者的工作流程不是医学标准。不要要求模型每次强制减法、填满处置栏目、输出固定数量动作或对用户评级。方法帮助 agent 选择，不替用户决定目标。

## 5. 医疗与产品边界

不进行疾病确诊、照片识诊、严重程度评分、个体化处方或医美决策。不编造因果、疗效承诺或精确恢复期限。不做品牌排行、带货和伪精确成分冲突表。

可解释产品类别、标签与研究局限，也可讨论用户提供的具体说法；结论应以相关证据和适用条件为依据，而非默认所有营销说法都无效。

## 6. 篇幅与维护

单篇不超过 9000 字符，不设最低字数或最低引用数量。删冗余而不是删适用条件；无需为满足配额增加数字、步骤或医学断言。

保持模块和被其他文件引用的小节标题稳定；改标题时同步导航与测试。AAD 原文和机器翻译不进入发布包，保留来源链接和独立撰写的知识内容。

## 7. 验证

- 引用审计通过，且重点事实完成原文支持范围核对。
- 问题有可用入口；模块、小节及来源路径没有断链。检索回归验证基本相关性，不要求一次找全或特定段落排第一。
- 沿具名关系可以补到相关概念、条件与例外；不为提升词面分数重复关键词或复制正文。
- 检查诊断式断言、固定就医等待期、跨疾病外推和旧强制流程是否残留。
- 用干净上下文实际问答，确认 agent 不需要主动抵抗知识正文才能正确回答。
- 记录实际核验的来源与未核验范围；自动测试和样例通过不等于全库医学认证。
