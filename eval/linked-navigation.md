## 自动验证

全套 74 项测试通过；引用标识解析 409 处、74 个唯一来源、0 问题。新导航测试检查目标文件、具名小节、入口可达性与模块间实际链接；关键主题连通检查排除了中央地图和框架/学习入口，不用地图的概念边伪造直接模块路径。

初次运行有一项旧排序断言失败：检索“洗后紧绷”命中了指向清洁小节的明确导航，而非指定正文。核对该路径可用后，将断言改为接受正文或具名链接，没有调整搜索权重来迎合旧测试。

实际 npm 打包包含概念地图，共 39 个发布文件；解包后从异目录运行 7 项导航测试全部通过。未发布 npm。

## 独立 Agent 实际路径

一个干净上下文子代理只读测试两个合成场景，未读取记忆或个人档案，未联网。以下是实际走过的路径，不是要求后续 Agent 照抄的流程：

1. **洗后紧绷且保湿刺痛**：[清洁](<../skill/references/01-清洁.md>)的洗后不适 → [刺激](<../skill/references/05-屏障与刺激.md>)的刺激/过敏区别 → [保湿](<../skill/references/02-保湿.md>)的“为什么有人越涂越干” → [就医](<../skill/references/10-何时就医.md>)的紧迫程度。补到了不能仅归因面霜、不能据感受确诊和不必等待固定周期的条件。
2. **油皮应趁湿还是等干**：[保湿](<../skill/references/02-保湿.md>)的用量和时机 → [肤质](<../skill/references/04-肤质与分龄.md>)的油皮语境 → [炎症性皮肤病](<../skill/references/08-炎症性皮肤病.md>)的玫瑰痤疮例外。能够区分一般建议与疾病情境，不把例外推广为所有油皮的规则。

两条路径均从目录和模块关系进入，没有依赖搜索排名拼答案；目标文件和具名小节均存在，无断链或缺少后续线索的阻断。最初两个模块读得偏宽，后续按具名小节局部读取；未遍历全库。

实际从段落来源解析了 [AAD 干燥护理](https://www.aad.org/public/everyday-care/skin-care-basics/dry/dermatologists-tips-relieve-dry-skin)与 [AAD 玫瑰痤疮护理](https://www.aad.org/public/diseases/rosacea/triggers/tips)的 URL。此次只验证中文段落到来源地址的路径，没有核验远端当前正文，不能据此声称医学事实全面认证。
