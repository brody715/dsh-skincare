# 08 炎症性皮肤病：先理解差异，再谈护肤品

反复泛红、瘙痒、脱屑或痘样丘疹并不自动意味着某一种病。这里介绍湿疹、接触性皮炎、脂溢性皮炎、玫瑰痤疮和银屑病的常见概念，供理解医生解释与准备就诊；不能靠症状表确诊。护肤可以辅助，不能取代需要的治疗，也不把这些病一概写成相同病程。

## 这一节最该记住的三件事

- 相似表现可以来自不同疾病；部位、颜色和接触史只是线索。
- 保湿、温和清洁与避免诱因有具体适用条件，不保证「三件套做对就少发作」。
- 治疗、药物剂量与停药方式需个体化；没有先做满四周护肤才能就诊的要求。风险判断见 [10-何时就医](<10-何时就医.md>)。

## 核心内容

### 一、湿疹 / 特应性皮炎：相关但不等同

湿疹是多类疾病的统称，特应性皮炎是其中常见的一类，不是二者完全等同。特应性皮炎可有干燥、瘙痒和炎症，常始于儿童期，但任何年龄均可起病；不传染。有的儿童随年龄改善，有的人长期反复，不能预言某人一定自愈或终身发作。[s:diseases/eczema/types/atopic-dermatitis]

不能用「先痒，后起疹」作为自我诊断规则，更不能说所有皮疹都是抓出来的。肤色也影响可见表现：AAD 婴儿示例中，浅肤色可见粉红或红疹，深肤色可呈深棕、灰或紫色，不能因没有鲜红色就排除炎症。[s:diseases/eczema/types/atopic-dermatitis]

**护理的角色。** 温和、无香精的霜或软膏可帮助减轻干燥与发作，但不能替代整个治疗计划。[s:diseases/eczema/types/atopic-dermatitis] AAD 儿童自护页建议温水短浴约 5–10 分钟、按需用温和无香精清洁剂、轻拍后保湿；已有外用药按医嘱使用。这个页面主要面向儿童，不能把其中用药顺序及频率当作所有年龄、所有制剂的统一规定。[s:diseases/eczema/types/atopic-dermatitis/self-care]

湿包裹、漂白浴等不是可随意添加的护肤步骤。AAD 建议对严重瘙痒或反复感染等特定情况先与儿童皮肤科医生讨论；本模块不提供配液或操作处方。[s:diseases/eczema/types/atopic-dermatitis/self-care]

**感染不能只靠外观确诊。** 湿疹与感染都可能渗液、肿胀或结痂。蜂蜜色痂、脓疱、疱疹样破损、扩散性红肿等提示需要医生判断；若儿童疑似感染并伴发热或流感样不适，AAD 建议立即就医，无发热且状态如常则联系其皮肤科医生。不要自行加抗生素或继续湿包裹来处理疑似感染。[s:diseases/eczema/childhood/health-concerns/infection]

### 二、接触性皮炎：找到那个东西，才治得好

刺激性接触性皮炎来自接触物对皮肤的损伤和刺激；过敏性接触性皮炎来自接触物触发免疫反应，可能数小时或数日后才出现皮疹。肥皂、清洁剂、长期湿作业等可能刺激皮肤，香精、镍等则是常见接触过敏原。[s:contact-dermatitis/causes]

「涂哪里，哪里起疹」有助回顾接触史，但不是对称分布就能确诊。过去耐受的产品也不能凭这一点免于排查。持续起疹或原因不明，医生需鉴别接触性皮炎、感染与其他问题；怀疑迟发接触过敏时可能做斑贴试验。[s:contact-dermatitis/causes] [s:patch-testing-rash]

停止接触已知诱因是重要环节；有时还需药物控制已有皮炎。并非只要「所有新产品停掉」就完成半套诊断，更不应通过再次涂可疑产品来证明过敏。方法细节见 [05-屏障与刺激](<05-屏障与刺激.md>)。

### 三、脂溢性皮炎：不是洗不干净

脂溢性皮炎可出现鳞屑性皮疹，常在头皮、眉间、鼻侧、耳周或胸部等区域；婴儿的乳痂属于相关表现。鳞屑可以干燥或油腻，肤色不同也可能呈红色、深色或较浅的斑片，所以不能仅凭「头皮屑多」「鼻翼红」确诊。[s:diseases/a-z/seborrheic-dermatitis-symptoms]

AAD 的相关自护页明确面向**青少年与成人**：温和清洗、充分冲净、洗后用无香精保湿，按医生建议使用药用洗发产品，并识别个人诱因。寒冷干燥、刺激性产品及压力可能参与发作，但不是每个人都由同一因素触发。[s:diseases/a-z/seborrheic-dermatitis-self-care]

药用洗发水可属于治疗，而不是「洗得更干净」的工具。不同年龄、部位与制剂用法不能互换；此处不把成人胡须区的浓度、频率复制给婴儿、眼睑或所有面部皮疹。焦油洗发产品可能改变浅色、漂染头发的颜色，需要留意。[s:diseases/a-z/seborrheic-dermatitis-self-care]

### 四、玫瑰痤疮：不是痤疮，别用祛痘思路

玫瑰痤疮可能有反复潮热、面中部持续变色、可见血管与痘样丘疹。深肤色可能表现为褐色、紫色或主要感觉发热；不是「深肤色表现完全不同」，也不是没有明显红色就可排除。它还可能累及眼睛，产生干涩、异物感、灼痛、畏光或视力变化等。[s:diseases/rosacea/what-is/symptoms]

它与痤疮不是同一疾病，但不能夸张为治疗方向全部相反：两者都可能需要减轻炎症与温和护理。对已诊断玫瑰痤疮，AAD 建议避免搓揉、磨砂和去角质，筛选无香精、耐受的产品；保湿有助舒适度与治疗效果，不是只供干皮使用。[s:diseases/rosacea/triggers/tips]

防晒是管理常见诱因的一部分：遮阴、衣帽及广谱、SPF 30 以上、抗水防晒。若防晒刺激，含氧化锌/二氧化钛且无香精的配方可能更易耐受，不保证任何矿物配方都不刺激。涂保湿易刺痛者可按该病自护建议等洗后皮肤干再涂，区别于一般干皮的趁湿保湿建议。[s:diseases/rosacea/triggers/tips]

面部泛红原因不明、祛痘产品越用越不适，可以暂停可疑非必要产品并咨询；不需要先做四周精简护理才能就医。眼部症状也不要仅用护肤品处理。[s:diseases/rosacea/what-is/symptoms]

### 五、银屑病：厚斑块加银白色鳞屑

干燥、隆起且常有银白色鳞屑的斑块是常见表现，常见于头皮、肘、膝和下背，但**不是所有银屑病都有银白鳞屑**。例如皱褶部位的反向型可能较光滑、少鳞屑；类型、部位和范围都会影响外观。不能凭「湿疹渗液、银屑病厚斑块」二分法自诊。[s:diseases/psoriasis/what/symptoms]

银屑病也可累及指甲，表现为点状凹陷、变色、碎裂或甲板分离；这些变化并非银屑病独有。患者出现关节肿痛、足跟痛或晨僵时应告诉医生，及时治疗关节受累有助防止进展。[s:diseases/psoriasis/what/symptoms]

少见的广泛脓疱型或红皮病型可危及生命：大面积皮肤异常、疼痛并明显全身不适，尤其伴发热、寒战时不能当普通鳞屑发作等待护肤起效。这里是风险提示，不教用户据描述给自己分型。[s:diseases/psoriasis/what/symptoms]

### 六、一张"以为是护肤问题"的对照表

此表是**就诊沟通线索**，不是「更像某病」的自动匹配器。多种病可以共存或相似。

| 可描述的表现 | 可向医生询问的方向与边界 |
| --- | --- |
| 面中部反复发热、变色、痘样丘疹 | 玫瑰痤疮等；并说明有无眼部不适。[s:diseases/rosacea/what-is/symptoms] |
| 鼻侧、眉区或头皮鳞屑 | 脂溢性皮炎等；不是简单判断清洁不足。[s:diseases/a-z/seborrheic-dermatitis-symptoms] |
| 某些接触后反复起疹 | 接触性皮炎等；记录接触史，不自行再暴露验证。[s:contact-dermatitis/causes] |
| 反复干燥、瘙痒和炎症 | 特应性皮炎等；年龄与肤色可影响表现。[s:diseases/eczema/types/atopic-dermatitis] |
| 隆起鳞屑斑、伴指甲或关节变化 | 银屑病等；外观不能代替鉴别诊断。[s:diseases/psoriasis/what/symptoms] |
| 嘴周、鼻周或眼周痘样小疹 | 口周/口周围皮炎等；可能痒、灼热或无明显感觉，患处可干燥脱屑。[s:diseases/a-z/perioral-dermatitis] |

口周皮炎尤其需要核对外用激素使用史。AAD 提醒：若自行用非处方氢化可的松，应停用；若是医生开的药，先询问开药医生能否停用或调整，不能把「所有越用越糟的药立即停掉」当通用规则。[s:diseases/a-z/perioral-dermatitis]

### 七、什么算一次"急性发作"

「发作」通常描述疾病活动或症状加重，不以范围扩大、睡不着或感染作为三条必备诊断标准。可记录与自己此前相比，范围、瘙痒、疼痛、渗液及生活影响如何变化；这是本项目沟通方法，不是医学评分。

新发或明显加重不等于全部急诊：呼吸/吞咽困难、眼唇突然肿胀需要立即帮助；快速扩散、疼痛、发热、起疱或疑似感染需要及时医疗评估。普通反复干痒也可以门诊咨询，不必先等待固定周数。[s:everyday-care/itchy-skin/rash/rash-101]

## 常见错误（用户最可能正在做的）

- 把湿疹全部等同于特应性皮炎，把所有炎症都说成过敏。
- 用颜色、鳞屑或单个部位直接给自己定病名。
- 把成人药用洗发水方案套到婴儿或眼周，把所有抗真菌/激素产品都归为同一种监管类别。
- 只保湿不处理疑似感染，或仅凭黄水就自行加抗生素。
- 所有药一律停、所有症状一律等四周，忽视已有医嘱与风险差异。

## 什么时候要停下来就医

反复不适、诊断不明或原治疗未控制时，可以安排皮肤科；儿童可联系儿科或原治疗医生。需要及时评估和急救的信号按 [10-何时就医](<10-何时就医.md>) 区分，不把儿童皮疹、眼周干痒或变化中的痣一律视作急诊。

## 自测

1. 「脸红又长小疙瘩，所以是玫瑰痤疮？」——不能这样确诊；说明症状、触发和眼部情况，让医生鉴别。
2. 「湿疹渗液就是感染？」——湿疹本身也可渗液；感染迹象尤其伴发热或全身不适，需要医疗评估。[s:diseases/eczema/childhood/health-concerns/infection]
3. 「有白屑就能用某款药用洗发水？」——先明确人群、部位和问题，成人头皮方案不自动适合婴儿或眼睑。
