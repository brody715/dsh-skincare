# 09 产品与标签：读懂信息，也识别信息的边界

包装可以提供成分、用法和警示，也会包含营销语言。关键不是先相信或一概否定，而是问：哪句话可验证、适用于谁、还缺什么？本节以 AAD 的美国消费标签语境为主，不能将 FDA 规则直接当成所有地区的法律。

## 这一节最该记住的三件事

- 防晒同时看广谱、SPF 和耐水条件；更高数字不替代足量与补涂。[s:understand-sunscreen-labels]
- 成分名、标称浓度、成品疗效是不同层面的信息，不能相互替代。[s:anti-aging/retinoid-retinol]
- “临床验证”“天然”“低敏”不能独自证明个人效果或绝对安全；应继续查证，而非凭词语给所有产品统一判死刑。[s:selecting-anti-aging-products][s:dry/pick-moisturizer]

## 核心内容

### 一、先决定要不要买，再决定买哪一个

AAD 用清洁、保湿、防护的基础框架解释如何控制预算，并提醒多种产品可能增加花费和刺激；这不是规定所有人最多三步，更不是无论目的是什么都先删产品。[s:care/skin-care-budget]

**精华是否必需？** 清洁、保湿与防护是 AAD 预算护理页给出的基础思路，额外产品不是补齐流程的必选项。[s:care/skin-care-budget] 项目讨论方法：用户没有额外困扰且现有流程舒适时，可以保持现状；若希望改善某个具体问题，再核对该成品的用途和证据。这不等于所有精华都无用，也不必为了精简而停掉原本合适的产品。

项目整理的购买问题：它针对什么具体困扰？是否与现有产品重复？有什么成品证据、适用条件和停止信号？这些问题帮助选择，不构成购买前的强制评估。

一次引入一款新抗老产品较便于辨认反应，也可减少短时间叠加刺激；这不等于所有多步流程必然有害。[s:selecting-anti-aging-products]

### 二、防晒标签：广谱、SPF 与耐水条件

优先读懂这三项关键信息，并结合所在地的标签标准：

| 标签 | 告诉你什么 | 没告诉你什么 |
| --- | --- | --- |
| 广谱 | 同时覆盖 UVA、UVB | 不保证所有光线或全天防护 |
| SPF 30 或更高 | AAD 建议的防晒伤指标范围 | 不是可以多晒多少小时 |
| 耐水 40/80 分钟 | 美国规定条件下的耐水时长 | 不是防水，也不免于擦干后补涂 |

SPF 15、30 过滤 UVB 的科普参考值约为 93%、97%，不等于每个用户的实际防护率。户外约每两小时补涂，并结合游泳、出汗、擦干与标签条件。“sport”“baby”“sensitive skin”“reef safe”没有该页面所述的 FDA 统一定义，不代表完全没有做过研究。[s:understand-sunscreen-labels]

用量见 [03-防晒](<03-防晒.md>)。AAD 用法页将多数成人身体裸露皮肤的参考量写为约一盎司，面部写为至少一茶匙，并以两指长作近似；不能将两指长当精确体积、把盎司直接按质量换毫升，或根据泛白程度判定防护。[s:how-to-apply-sunscreen]

防晒棒每块区域来回四遍再揉匀；喷雾充分喷至发亮后揉匀，避免吸入、直喷脸口、风大和热源明火。用几次取决于面积，不能凭“一瓶用很久”直接诊断少涂。[s:how-to-use-stick-spray-sunscreens]

PA 等其他市场标识需查询相应标准，不仅凭是否含氧化锌等成分倒推出成品 UVA 防护等级。本节不提供未经核对的跨标准换算。

### 三、成分表：先看它分不分类

**“活性成分”须放回法规语境。** 在美国防晒药品标签中，它指承担 UV 防护的成分；氧化铁帮助防护可见光，可能列在非活性成分中。这不能推广成“所有护肤品只有防紫外线成分才算活性”。[s:understand-sunscreen-labels][s:routine/fade-dark-spots]

**浓度不总能读出。** AAD 指出非处方视黄醇没有统一强制披露百分比的要求；但有些产品会主动标，有些药品另有要求。不能笼统说所有浓度都不印包装，也不能把未标等同低浓度。[s:anti-aging/retinoid-retinol]

成分表可以帮助发现已知过敏原和感兴趣的成分类别，但不能单独给出疗效或刺激评分。此处不采用“排在香精、防腐剂后就低于 1%”的推断：缺少具体地区标准和配方信息时，顺序不足以算出剂量。

不含香精与无味不是等同信息：“unscented”或植物来源产品仍可能含香精相关成分；已知香精过敏者可看“fragrance-free”，同时核对实际成分。[s:prevent-skin-problems/test-skin-care-products] “天然”不等于低敏，植物也能致敏。[s:dry/pick-moisturizer]

### 四、把名字对上：常见写法对照

以下是名称辨认辅助，不是等效替换或功效推荐表。不同分子、盐或同类成分不能因同在一行就当同一个东西。

| 常见中文 | 对应写法 | 要区分的地方 |
| --- | --- | --- |
| 甘油 | Glycerin / Glycerol | 名称辨认不推导浓度 |
| 透明质酸 | Hyaluronic Acid | Sodium Hyaluronate 是透明质酸钠，不是同一标签名 |
| 凡士林 | Petrolatum / Petroleum Jelly | 成品仍需看用途与说明 |
| 聚二甲基硅氧烷 | Dimethicone | Cyclomethicone 是另一类环状硅氧烷，不是同义词 |
| 视黄醇 | Retinol | Retinal 是视黄醛，Retinyl Palmitate 是视黄醇棕榈酸酯，不能互换百分比 |
| 水杨酸 | Salicylic Acid | BHA 是类别缩写，不能总当成该单一成分的正式名 |
| 甘醇酸、乳酸 | Glycolic Acid、Lactic Acid | 两者均属 AHA，但不是同一种酸 |
| 过氧化苯甲酰 | Benzoyl Peroxide / BPO | 属痤疮药物成分，不等同美容“漂白剂” |
| 氧化锌、二氧化钛 | Zinc Oxide、Titanium Dioxide | 防晒活性成分，仍要看成品标签 |
| 氧化铁 | Iron Oxides | 有色防晒中可见光防护的线索 |

名称表属于项目通用术语整理；具体商品的译名、成分、浓度须核对其标签，不据此生成处方。维 A 类和防晒分类分别见相关 AAD 页面。[s:anti-aging/retinoid-retinol][s:understand-sunscreen-labels]

### 五、剂型与使用体验：名称不等于渗透深度

**剂型影响肤感、保湿和使用方式，但只看“凝胶/乳霜”无法确定成分到达皮肤哪一层。** AAD 的一般描述是凝胶较轻，乳霜通常比乳液厚、含油更多，软膏更封闭，干燥者常更适合乳霜或软膏；不代表所有成品严格按名称排序。[s:dry/pick-moisturizer]

选择应结合干燥程度、出油区域与耐受；同一人可分区调整，而非为了套肤质标签整脸用同一种量。也不从两个产品都含硅酮推导必定搓泥，或规定换剂型后必须等一周才能叠加。[s:dry/pick-moisturizer]

### 六、包装、保存与开封后期限

盖紧、清洁干燥、按说明温度存放、避直晒并查有效期，是 AAD 的基础建议。包装形式不是污染风险的唯一决定因素，不给所有罐、滴管、泵瓶排固定安全榜。[s:care/skin-care-budget]

美国化妆品可能标有开罐图案和 M（月数），表示开封后参考使用期；该信息并非美国所有化妆品都强制标注。记录开封时间，产品变色、异味、分层或质地变化时不要只因为没到期就继续用。AAD 给睫毛膏约三个月更换的建议，不能推广到全部彩妆。[s:replace-makeup-sunscreen]

防晒看实际有效期；未标日期时可记购买日期。AAD 说明 FDA 要求防晒保持原效力三年，但这不是“无论怎么存放都保证三年”：高温、车内或直晒可使其提前变质。[s:replace-makeup-sunscreen]

**过氧化苯甲酰需单独看。** AAD 2025 年 FAQ 说明，高温、久存可促其分解；FDA 检测的 95 款中，超过 90% 的苯为未检出或极低，并非全都未检出。其消费者建议是按包装保存（一般室温或更凉）、每 10–12 周更换，丢弃受较高温度影响的产品（举例超过 78°F，约 25.6℃）。这是该页的谨慎管理建议，不是证实一越温就达到致癌剂量，也不是所有护肤品的统一温度线。具体储运不明或想换治疗时询问药师/医生，不自行将其他药物当等效替代。[s:benzoyl-peroxide-faqs]

### 七、宣称与证据等级

不按营销词直接赋予“强、中、弱”分数，改问它实际对应什么证据。

| 宣称 | 可以怎样理解 | 还应核对 |
| --- | --- | --- |
| 广谱、SPF、耐水 | 对应特定测试指标 | 市场标准、实际用法、有效期 |
| 临床验证 | 单凭短语不足以证明受控临床试验或 FDA 批准 | 完整研究、对照、样本、终点和成品是否相同 |
| 不致痘、低敏 | 产品选择线索 | 不能保证个人零痘、零过敏 |
| 天然、有机 | 来源或生产相关描述 | 不自动等于安全或有效 |
| 一夜年轻十岁、包治皮肤病 | 夸大效果的风险信号 | 不凭广告开药或延误诊断 |

AAD 抗老选购页确实用消费者试用解释“clinically proven”，并警告其不等于临床试验加 FDA 批准。本节取其可支持的结论：**这几个字本身不能证明研究质量**，而不是反过来断言所有带这句话的产品绝对没做过临床试验。有效产品也并非只有高价位。[s:selecting-anti-aging-products]

补剂同样不能只看美容承诺。AAD 提醒美国补剂上市前不必像药品那样先提交安全有效证明；这不应简化成“完全不受任何监管”。独立验证标志主要帮助核对成分，不等于证明某美容功效。是否需要、剂量与相互作用应结合医生建议；生物素还可能干扰血液检查。[s:routine/supplements-for-your-skin]

### 八、价格、预算与「值不值」

价格不是疗效试验。优先保留符合需求、能正确使用的基础护理；额外产品需有具体目标，不因为预算宽裕就自动增加活性或医美。[s:care/skin-care-budget][s:selecting-anti-aging-products]

可计算每次按说明用量的成本、是否会用到过期，但不能无比较试验就保证“便宜足量一定胜过任何贵产品”。医疗操作的适应证、风险、恢复期和费用属于另一次与医生的讨论，不能列为高预算护肤必选项。[s:diseases/acne/derm-treat/scars/treatment]

### 九、继续用还是停：一张时间表

时间窗只提供预期，不是出问题仍要熬满的规定。

| 情况 | 有条件的时间参考 |
| --- | --- |
| 新品小面积试用 | AAD 通用页建议每天两次、7–10 天；无反应不能排除以后过敏 |
| 抗老保湿 | 数天内可让细纹外观看起来较饱满，不等于永久填平 |
| 多数抗老产品 | 至少约六周，有时三个月；依成品、目标和耐受不同 |
| 炎症后深色斑 | 诱因已停止后，浅些的常需 6–12 个月，更深可数年；不是所有色斑的时间表 |

对应来源分别为产品测试、抗老效果及深色斑页面。[s:prevent-skin-problems/test-skin-care-products][s:anti-aging/maximize-anti-aging-products][s:routine/fade-dark-spots]

小面积试用用正常用量、厚度和停留时间；洁面等洗去型产品遵循自身说明，不因网页举了五分钟就把任何洁面强行留五分钟。发红、发痒、肿胀时洗掉停用；严重或持续反应就医。医学斑贴试验与家庭试用不是同一件事。[s:prevent-skin-problems/test-skin-care-products]

对刺激性处方治疗，联系开药医生确认是否预期反应及如何调整；不要以“处方不能自己停”为由强忍明显恶化或严重反应。[s:anti-aging/maximize-anti-aging-products] 孕期尤其需区分禁用与限用：AAD 将高浓度水杨酸（超过 2%）放在先与医生讨论并限制使用的类别，不是一律禁用，也不是给低于该值无限使用的保证。[s:routine/pregnancy-skin-care]

## 常见错误（用户最可能正在做的）

- 从一个成分名直接推出成品效果，或把同类分子当同义词。
- 把“临床验证”当批准，也把它反向当作“肯定没有试验”。
- 把 7–10 天无反应当永久不过敏，把见效窗口当必须忍耐期。
- 用单一法规或美国处方地位推断其他市场。

## 什么时候要停下来就医

明显反应、持续或反复皮疹、变化中的斑点或痣，先处理风险再谈性价比。严重反应的紧迫程度按 [10-何时就医](<10-何时就医.md>) 判断，不要求先试满若干天。无法定位反应成分时，医生可能安排斑贴试验。[s:prevent-skin-problems/test-skin-care-products]

## 自测

1. 有临床验证四个字就有效吗？需看具体研究，不能保证个人结果。
2. Retinol 和 Retinal 是一个成分吗？不是，不能直接互换浓度。
3. 试用十天没事能保证上脸安全？不能，只是有限部位、有限时段的观察。
4. 防晒没到期但在热车里放了很久？高温可能提前变质，不能只依赖日期。
