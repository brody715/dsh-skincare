# 04 肤质与分龄

肤质描述帮助讨论当前护理需求，不是诊断，也不是回答问题前必须完成的分型。年龄、生命阶段、环境和治疗可能改变需求，但不能仅凭年龄推定激素状态或皮肤病。刺痛泛红见[屏障与刺激](<05-屏障与刺激.md>)，痘见[痤疮](<06-痤疮.md>)，标签见[产品与标签](<09-产品与标签.md>)。

## 相关知识与继续查找

- [保湿](<02-保湿.md>)「按肤质和季节分」——从油皮或混合皮问题继续读，核对部位、治疗和耐受条件。
- [清洁](<01-清洁.md>)「频率、水温、时长」——年龄与洗浴频次有关时，保留各来源的人群范围。
- [屏障与刺激](<05-屏障与刺激.md>)「7. 不要用屏障受损替代疾病鉴别」——所谓敏感肤质伴持续不适时，补描述与诊断的区别。
- [抗老与光老化](<12-抗老与光老化.md>)「8. 孕期、敏感肌和色沉：区分避免、限用与个体评估」——特殊生命阶段涉及成分时，核对限制与个体评估边界。

[概念导航](<../knowledge-map.md>)可返回公共地图；地图仅用于定位，不是医疗依据。

## 这一节最该记住的三件事

- 观察当前部位和表现，比把「干皮／油皮」当永久身份更有用。这是教学方法，不是临床分型测试。
- 剂型和清洁方式按干燥、出油、耐受和用药调整，而非按价格或年龄购买整套产品。[s:dry/pick-moisturizer]
- 年龄建议要保留人群条件：新生儿不是所有婴幼儿，儿童洗澡规则不是成人规则，围绝经期也不是所有 45 岁者。[s:newborn-bathing] [s:child-bathing] [s:skin-care-during-menopause]

## 核心内容

### 1. 肤质描述：观察当前表现，不作永久分型

不要求先定好肤质才能获得护理信息。AAD 的通俗描述如下：[s:skin-care-budget]

| 描述 | 常见表现 | 解释边界 |
|---|---|---|
| 敏感 | 用产品后可能刺痛、烧灼 | 不是「皮肤天生薄」的证明，也不能替代皮炎评估 |
| 中性 | 通常较清爽、无明显敏感 | 不代表不会出现刺激或疾病 |
| 干性 | 起皮、痒、粗糙 | 这些表现也可能见于疾病 |
| 油性 | 发亮、油腻 | 出油不等于不需要保湿或没有干燥 |
| 混合性 | 不同部位干油不同 | 可以按部位调整，不等于必须买两套 |

这套描述是选品沟通语言，不是互斥且终身不变的诊断类别。拿不准、尤其持续不适时，可以咨询皮肤科医生，不强迫用户完成问卷或仪器测量。[s:skin-care-budget]

### 2. 家庭自测：只用眼睛和手感，不用仪器

这里的「自测」只是**可选的作者观察方法**，不是经过验证的试验：回想日常洗后是否紧绷、白天哪里发亮、哪些产品用后不适、是否因季节或治疗改变。可按 T 区和两颊分别描述，不要求打分或长期记录。

不要为了判断肤质洗后空置 30 分钟，也不用故意试刺激产品。需要保湿时照常保湿；微湿时涂本来就有助减少水分流失。[s:dry/pick-moisturizer]

AAD 保湿选品页把部分混合皮患者比作「两张脸」，但原文的「中央不涂」是对**部分患者**的具体建议，不是所有人的禁令。可减少不需要区域的用量，若 T 区也干、刺激或正在用药，仍要按实际需求处理。[s:dry/pick-moisturizer] [s:acne/skin-care/moisturizer]

### 3. 干皮：护理反应与何时求助

**两周不是疾病与非疾病的分界线，也不是必须等待的期限**。AAD 概览说，干燥自护有效时通常在两周内改善；持续或加重时可能涉及基础疾病、药物、接触物或年龄，需要医生查原因。[s:dry-skin-overview]

低湿度、室内暖气相关干燥可通过护理改善；较干时霜或软膏通常比乳液更能保水。[s:dry-skin-overview] 温和清洁、温水短浴、洗后和觉得干时保湿，是干燥护理选项。[s:dry/dermatologists-tips-relieve-dry-skin]

保湿后改善不排除湿疹等疾病；反复干痒红也不能在对话中直接确诊湿疹。持续干燥、自护无效、疼痛、裂口出血，或者涂保湿也烧灼刺痛时，应咨询医生而非继续加量。[s:dry/pick-moisturizer] [s:dry/dermatologists-tips-relieve-dry-skin]

不能把普通干皮描述为必然导致永久食物过敏。AAD 概览对某些风险使用关联性措辞，尤其提到 60 岁以上、非常干燥的人可能增加感染和压疮风险；适用条件不能省略。[s:dry-skin-overview]

### 4. 油皮：先承认油有好处

AAD 油皮页指出油脂有保护作用，油皮人群往往皮肤较厚、皱纹较少；这是总体倾向，不保证某个人不光老化，也不是追求更油的理由。[s:dry/oily-skin]

该页的实用建议包括：

- 洁面一天最多两次及出汗后，使用温和洁面，不搓洗，不追求发涩。
- 选 oil-free、noncomedogenic 等标签的产品；减少油光的酸类可能刺激，出现刺激时停用或减少频次。
- 洁面后保湿，户外防晒并结合遮阴和衣物；不带妆睡觉。
- 油光困扰时可用吸油纸轻压数秒，不来回摩擦。[s:dry/oily-skin]

另一保湿选品页提到部分油皮可考虑少涂、跳过油区或用凝胶。两页侧重不同，不能摘一句变成所有油皮必涂或绝不能涂的规则。[s:dry/pick-moisturizer] 尤其痤疮治疗引起干燥时，保湿可帮助耐受；4–8 周痘减少的数据来自含药物的联合方案，不是单用保湿控油祛痘的疗效保证。[s:acne/skin-care/moisturizer]

### 5. 毛孔和粗糙：能改的是「看起来」

AAD 讨论的是让毛孔**不那么显眼**：堵塞、油腻、炎症及皮肤松弛都可能影响外观。温和清洁、不致痘产品、处理痤疮、防晒以及部分人适用的视黄醇或去角质可能有帮助。[s:face/treat-large-pores] 不承诺永久消除毛孔，也不把它概括为「只能改变干净度」或「防晒是唯一有效手段」。

该页对视黄醇／视黄醇棕榈酸酯的建议涉及油性、轻度痤疮或皮肤紧实度下降者，并提醒可能刺激，孕期及哺乳期不使用这些产品。[s:face/treat-large-pores] 这不是所有人到某个年龄必须开始的项目。

去角质并非人人需要。干性、敏感、易痘者更易被机械摩擦刺激；深肤色或炎症后易留深色印者应避免激进去角质。已有伤口或晒伤时不做，做后保湿，频次按方法与耐受。[s:safely-exfoliate-at-home] 不能把原文的温和选项翻成「干敏痘皮都适合毛巾加化学剥脱」。

### 6. 分龄：改的是优先项

下表是来源适用范围，不是强制用户按年龄完成护理任务：

| 人群／阶段 | 该来源支持的重点 | 不应外推为 |
|---|---|---|
| **新生儿** | 通常每周洗浴 2–3 次，前提是每次换尿布彻底清洁；脐带残端脱落愈合前擦浴；洗后干可无香精保湿或减少洗浴 [s:newborn-bathing] | 所有婴幼儿均按此次数 |
| **6–11 岁儿童** | 每周至少 1–2 次，弄脏、游泳、出汗有体味时加洗；每日洗也可以；皮肤病按医生要求 [s:child-bathing] | 儿童每日洗都过度，或成人也只需每周一两次 |
| **青春期开始后** | 每日洗浴、每日洗脸两次，运动、游泳或大量出汗后清洁 [s:child-bathing] | 青春期痤疮只是卫生问题 |
| **20 多岁女性为原文主要对象** | 温和洁面、防晒，针对具体诉求选择产品，并可随季节调整 [s:skin-care-in-your-20s] | 所有 20 岁者只能用两样、必须加维生素 C 或维A酸类 |
| **40–50 多岁** | 防晒、保湿、温和清洁，不室内美黑，戒烟、健康饮食、睡眠；也可讨论抗老产品 [s:skin-care-in-your-40s-and-50s] | 该年龄的所有产品收益已被定量证明远低于防晒 |
| **60–70 岁，尤其干燥者** | 温水短浴、温和无香精清洁、及时保湿；药物和疾病也可能参与干燥 [s:skin-care-in-your-60s-and-70s] | 所有瘙痒都是老化，只要减少洗澡即可 |
| **围绝经／绝经相关变化** | 可能干、薄、松弛，也可能长痘；按表现护理，持续皮疹、脱发等需评估 [s:skin-care-during-menopause] | 每位中年女性同样变化，或凭年龄和长痘就确认绝经 |
| **孕期／备孕** | 核对药物和产品，温和清洁、保湿、防晒；有禁用或需谨慎成分 [s:pregnancy-skin-care] | 成分安全表可替代产科／皮肤科的个体决策 |

**新生儿洗浴还涉及安全。** AAD 强调备齐用品、保持保暖，始终一只手扶着婴儿；用手腕内侧确认水温不烫，洗后及时包裹。不能只留下「每周几次」而省掉照护条件。[s:newborn-bathing]

**青少年痤疮要认真对待。** 「以后自然会好」可能使治疗延误，痤疮可影响自尊，重度者可能留下瘢痕。AAD 所述家长每天催用药反而降低依从性来自一项小研究，不意味着所有提醒都有害；应和青少年商量支持方式。[s:acne-teenage-five-ways-to-help] 情绪明显低落、回避社交需要关心并寻求适当帮助，不能把所有心理困扰都只归给皮肤。

**20 多岁的页面并不要求固定“只加一件”。** 它鼓励针对主要困扰选择科学支持的成分、保持可调整和个体化。其 20–30 分钟是洗脸后到夜间维A酸类之间，或先保湿再等候的用法例子，不是早维 C 与晚维A酸类之间的间隔。原文美国非处方阿达帕林信息不能当作各地都可自行购买和使用的授权；用药见[痤疮模块](<06-痤疮.md>)，本节不作处方决策。[s:skin-care-in-your-20s]

**60–70 岁干燥护理的具体例子。** 温水洗浴 5–10 分钟、软布轻洗、轻拍留少量水，沐浴后 3 分钟内及白天按需要使用无香精霜，极干时可考虑软膏；有些人不必每天洗。沐浴油可能增加滑倒风险，该页建议避免。发现斑点与其他不同、变化、发痒或出血应看医生，而非直接当老年斑。[s:skin-care-in-your-60s-and-70s]

**绝经相关变化不等于不可改善。** 来源讨论皮肤保水能力下降、松弛、毛发变化和可能的痤疮；保湿、防晒或治疗可以有帮助。胶原下降数字是该页对特定生命阶段研究的概括，不能用于预测个体损失，因此本节不设个人百分比。脱毛也不是一律禁蜜蜡：原文是皮肤过薄时可能撕裂出血，应先评估。[s:skin-care-during-menopause]

**孕期既要辨风险，也要避免过度禁用。** AAD 孕期页列出应避免的维A酸类（含视黄醇、阿达帕林等）、氢醌、非那雄胺、螺内酯、四环素类及 5-氟尿嘧啶；备孕或已孕应将所有药物和处方护肤告知产科、皮肤科，及时由医生调整。[s:pregnancy-skin-care] 对高剂量水杨酸（>2%）、过氧化苯甲酰及部分其他成分，该页的表述是有限使用／研究不足并需与医生讨论，不能改成「全部已证实致畸」或自行给出安全剂量。香精、某些酒精和硫酸盐的建议在该页属于减少刺激，不等于整类成分都对胎儿有害。[s:pregnancy-skin-care]

**不按性别或年龄套产品。** 可根据剃须、用药、工作环境和实际干油程度讨论，而不要求先购买“男士”或“熟龄”系列。这是作者的讨论原则。成年人新发痘也不应直接归因为更年期；先核对表现和背景，必要时医疗评估。

## 常见错误（用户最可能正在做的）

- 洗后故意不涂东西等待半小时，用结果确定永久肤质。
- 混合皮 T 区永远禁保湿，或必须买两套。
- 将好转当成排除疾病，或把两周当强制等待期。
- 把儿童、老年、孕期或特定疾病建议推广到全人群。
- 以年龄确认更年期、疾病或某个必需成分。
- 把 AAD 美国用药可及性当作本地自行用药指令。

## 什么时候要停下来就医

持续或加重的干燥、明显疼痛、裂口出血、保湿也刺激，需咨询医生，不必等满两周。[s:dry/pick-moisturizer] 新发、变化或与其他不同的斑点，尤其发痒或出血，不要自行当作色沉处理。[s:skin-care-in-your-60s-and-70s] 孕期药物疑问和持续皮肤问题应交给产科／皮肤科评估。[s:pregnancy-skin-care]

有渗液、快速扩散、明显全身不适等表现时，按[就医模块](<10-何时就医.md>)判断紧迫程度。本模块不诊断感染，也不规定所有皮疹等待同样的天数。

## 自测

1. 「油皮不能用保湿霜？」不是；看是否干燥、正在用药和配方耐受，不能仅按剂型禁用。
2. 「62 岁小腿一直痒，只有保湿可做？」不是；可回顾温水短浴和保湿，同时评估持续瘙痒，不能只按年龄定因。[s:skin-care-in-your-60s-and-70s]
3. 「45 岁突然长痘又干，一定更年期？」不能确定；年龄和表现只是线索。
4. 「T 区油、两颊干，要买两瓶吗？」不一定；先考虑分区用量和当前配方是否适合。[s:dry/pick-moisturizer]
5. 「新生儿每周洗两三次，所以两岁孩子同样照做？」不能如此外推，应另核年龄适用建议。
6. 「13 岁长痘，等长大就好？」不宜因此忽略困扰；及时讨论治疗和心理影响。[s:acne-teenage-five-ways-to-help]
