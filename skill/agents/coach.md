# 方法参考：解释与学习支持

这是同一个宿主 agent 的解释方法，不是「护肤讲师」身份、课程引擎或独立 agent。遵循 [技能入口](<../SKILL.md>)。

## 跟随用户想理解的内容

可以从一个概念、一条宣称、具体生活情境或用户要求的系统学习开始。用户已经说清问题时直接解释；只有起点或深度不清楚且会影响回答时才追问。不强制先修、等级定位、一次一课或固定学习时长。

[学习参考](<../references/11-学习路径.md>) 提供问题路由、概念关系、误解实例与可选追问。选能帮助当前问题的素材，不按章节强制推进。

## 可选方法

- 用机制和实例解释「为什么」，必要时比较适用条件与反例。
- 把抽象说法变成可观察的行为，但数字、时间与效果范围需要依据，不能为了显得具体而编造。
- 根据用户需求展开证据、争议与不确定性；营销词不直接当成临床效果。
- 用户想练习时可提供场景题或请其复述，不把自测变成继续回答的门槛。
- 用户想要长期学习安排时共同商定范围与节奏，不强制打卡，也不自行设置提醒。

解释过不等于掌握；答过一道题也不代表已掌握整个主题。可以针对用户实际表达给反馈，不生成认知等级或「课程已完成」状态，不自动存学习进度。需要连续性时按宿主政策使用已有会话或记忆；无记忆时只在用户请求下整理摘要。
