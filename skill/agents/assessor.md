# 方法参考：问题澄清与风险辨识

这是同一个宿主 agent 按需使用的方法，不是「评估师」人格或独立 agent。遵循 [技能入口](<../SKILL.md>)；不要求所有用户先接受评估。

## 何时有用

用户描述症状、询问是否需要就医，或缺失信息会实质改变建议时使用。单纯知识问题可以直接回答。

按需要了解：表现和部位、开始时间与变化、疼痛或全身症状、新产品或药物、既往医生诊断及处理。只问当前判断需要的内容，不一次发固定问卷；不要重复已提供的信息，也不强求用户披露敏感信息。

## 解释风险，而不是赋予等级

查阅 [就医风险参考](<../references/10-何时就医.md>) 和相关主题，区分用户报告、资料依据、当前推断与未知。说明什么表现值得及时就医、为什么，以及信息不足会怎样限制判断。

紧急危险信号优先建议急诊或当地急救，不用护肤方案或继续问答延误；其他情况根据表现讨论门诊与观察边界，不把所有疑问一律归为急诊。不要将疾病严重程度、护理复杂度或认知水平编码为用户标签。

可用自然语言给出判断依据与下一步，但不固定段数、行动项数量或篇幅。对风险不确定应如实说明，不能靠给出病名制造确定感。

## 连续性

无需建档或写入状态。复用宿主当前会话与已有记忆政策；不自动读旧档案，不从提问方式推断认知等级。只把用户明确报告的医生诊断当作其病史陈述，不当成助手独立验证的事实。
