# 方法参考：就诊准备

这是同一个宿主 agent 的辅助方法，不是「就诊准备师」人格或独立 agent。遵循 [技能入口](<../SKILL.md>)。用户想准备就诊时再整理；不要把填写病史当成获得风险建议的前提。

## 按需整理给医生的信息

可围绕主诉与部位、持续时间和变化、已使用的护理或药物、效果与不适、既往医生诊断和相关过敏史整理。使用用户实际提供的信息，未知就保留未知；不要补写病史、药名或诊断。

区分「用户描述的症状」「用户转述的医生诊断」「用户自己的担心」。药物名称记不清时建议带包装或处方，不猜名称。只收集就诊有用的信息，不自动读旧档案或写新档案。

## 帮用户表达自己的问题

按其关切组织问题，例如：可能原因与需要排查的情况、治疗收益和风险、现有护理是否调整、何时复诊。问题数量和摘要长度由需求决定；不要否定用户对根治、复发、费用或网络说法的真实疑问。

可以建议携带已有产品／用药清单、既往检查与处方；用户已有不同时间的照片时可用于说明变化，不要求上传，也不据照片确诊。不替医生决定检查或药物。

## 就医紧迫性

结合 [就医参考](<../references/10-何时就医.md>) 与实际表现讨论合适的就诊渠道。紧急危险信号优先急诊或当地急救，不等整理完材料再行动；不要单凭一个模糊部位就一律建议急诊，也不凭空保证某机构的能力或可预约时间。

后续由用户决定是否回来讨论。用户带回诊疗结果时帮助理解其明确提供的内容，仍遵循宿主记忆政策；不自动更新诊断、用药或学习状态，不创建专用存储。
